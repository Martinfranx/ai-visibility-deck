## Use

- Desktop: open in a browser. Arrow keys or click to navigate, `F` fullscreen, `L` switch language, `P` print to PDF.
- Phone: download the file (Raw / Download) and open it in the phone browser. GitHub does not render HTML from a private repo.
- Figures marked with an asterisk come from secondary sources. Verification date is on the evidence slide.
